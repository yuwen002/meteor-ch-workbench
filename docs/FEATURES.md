# 功能说明

## 连接管理

- **新建连接** — 左侧栏底部点「+」或右键分组 → 新建连接，支持 Native / HTTP 协议、TLS、LZ4 压缩
- **测试连接** — 保存前可先测试连通性，失败信息直接显示
- **分组拖拽** — 连接可拖入拖出分组，支持重命名和删除分组
- **断开重连** — 右键连接 → Disconnect，下次查询自动重连

## SQL 编辑器

- **快捷键执行** — `Ctrl/Cmd + Enter` 执行当前选中 SQL（无选中则执行全部）
- **Monaco Editor** — SQL 语法高亮、自动补全、多光标
- **结果表格** — 列宽自适应、耗时统计、行数统计
- **错误展示** — SQL 错误直接在结果面板里显示，不是弹窗

## 数据库 / 表 / 视图浏览

- **侧边栏树** — 点击数据库名展开，默认显示该库所有**表**；如果库里有视图，会在表下方单独展示「**视图**」分区（眼睛图标，悬停显示引擎）。普通 `View`、`MaterializedView`、`LiveView` 都会被归入视图区。
- **单击表名 / 视图名** — 直接在结果面板**预览数据**（自动 `SELECT * FROM db.name LIMIT 10` 并执行），选中项高亮标识
- **右键表名 / 视图名** — 菜单支持：
  - `SELECT * LIMIT 10` — 快速预览前 10 行
  - 查看 DDL — `SHOW CREATE TABLE` 结果写入编辑器
  - 编辑表结构 — 打开编辑 Modal
  - 删除表 — 带红色确认弹窗

## 可视化建表

**入口**：鼠标悬停数据库名 → 右边小 `+` 按钮，或右键数据库 → "在此数据库创建表"

支持配置：

| 字段 | 说明 |
|---|---|
| 表名 | 必填 |
| 注释 | 可选 |
| 引擎 | 下拉选择（26 种常用），默认 MergeTree |
| ORDER BY | MergeTree 系列必填，自动提示 |
| PARTITION BY | 可选 |
| PRIMARY KEY | 可选，不填则用 ORDER BY |
| SETTINGS | 可选，如 `index_granularity = 8192` |
| 列定义 | 名称 / 类型（下拉 42 种） / 默认值 / 注释，支持上下移动、删除 |

底部实时 **SQL Preview** 面板，提交前可直接确认。

## 可视化编辑表

**入口**：右键表名 → "编辑表结构"

打开后自动从后端加载当前表结构，三类变更操作：

| 操作 | 标记 | 生成 SQL |
|---|---|---|
| 修改列类型 / 默认值 / 注释 | 蓝色 **MOD** | `ALTER TABLE ... MODIFY COLUMN ...` |
| 重命名列 | 黄色 **REN** | `ALTER TABLE ... RENAME COLUMN ... TO ...` |
| 新增列（支持 FIRST / AFTER） | — | `ALTER TABLE ... ADD COLUMN ...` |
| 删除列 | 红色 **DROP** | `ALTER TABLE ... DROP COLUMN ...` |

底部实时预览所有变更对应的 ALTER 语句，按顺序逐条执行，中途失败会报出具体哪条 SQL 出错。

> **边界处理**：编辑表时，如果某列当前类型不在 42 种预设里（如 `Decimal(15, 4)`），它会自动加入下拉选项，不会丢失原值。

## 集群面板

- 自动查询 `system.clusters` 展示所有集群、分片、副本
- 每行可点击，自动生成 `remote()` / `cluster()` SQL 片段插入编辑器

## 国际化

- 首次启动自动检测系统语言（zh-CN / 其他 → en）
- 右上角地球图标一键切换
- 偏好保存在配置里

## 配置文件

连接信息存储在用户目录的 `connections.json`，可通过菜单「打开配置文件夹」快速定位。
