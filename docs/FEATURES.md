# 功能说明

## 连接管理

- **新建连接** — 左侧栏底部点「+」或右键分组 → 新建连接，支持 Native / HTTP 协议、TLS、LZ4 压缩
- **测试连接** — 保存前可先测试连通性，失败信息直接显示
- **分组管理与旧配置兼容** — 启动时读取旧 `connections.json` 中的 `folders`、连接 `folder_id` 和原始顺序；保留分组 ID / 名称及连接归属，支持新增、重命名、删除、折叠和将连接移入 / 移出分组。分组与组内连接可通过「更多 → 上移 / 下移」调整顺序，写回本地配置并在重启后保留；删除分组不会删除连接，而是将其移到「未分组」
- **断开重连** — 右键连接 → Disconnect，下次查询自动重连

## SQL 编辑器

- **快捷键执行** — `Ctrl/Cmd + Enter` 执行当前选中 SQL（无选中则执行全部）
- **取消查询** — 查询运行中，运行按钮变为「取消」，点击立即中止；取消后显示灰色提示（与红色 SQL 错误区分）。关闭仍在运行的标签页也会自动取消
- **多标签页** — 同时开多个查询标签，各自独立的结果 / 错误 / 加载状态；双击标签可重命名；切换标签自动保存并恢复滚动位置与光标
- **Monaco Editor** — SQL 语法高亮、多光标
- **SQL 自动补全** — 输入时按上下文给出候选，纯前端实现（后端零改动）：
  - `FROM` / `JOIN` / `INTO` 之后补全库名与表名，确认后插入 `` `db`.`table` `` 全限定形式
  - `db.` 或 `FROM db.t AS x` 的别名后补全该表列名；`SELECT` 列表同时给出列名与表名
  - 其余位置补全 ClickHouse 关键字与常用函数（函数自动带左括号），右侧显示返回类型或所属库
  - 光标位于注释（`--` / `#` / `/* */`）内不触发；库表列清单按连接缓存 2 分钟，连续输入不会反复打后端，切换连接自动失效
- **结果表格** — 列宽自适应、耗时统计、行数统计
- **结果集搜索（DBeaver 风格）** — 结果工具栏内嵌搜索框，输入即过滤，全列忽略大小写子串匹配；`Esc` 或点右侧 × 清空。命中时工具栏显示「筛选 N / 共 M 行」，无命中时表格区显示「没有匹配「xxx」的行」并提供「清空搜索」。表头右键「仅在 xxx 中搜索」可把搜索范围收窄到单列，之后在搜索框里继续输入即可。搜索是**本地**行为，只过滤已加载的结果，不发新查询；它与服务端筛选、服务端排序可以叠加
- **列排序（DBeaver 风格）** — 表头**仅右键**弹出菜单（左键不再弹菜单），提供「Order by 列名 ASC」「Order by 列名 DESC」两项；选中后生成 `ORDER BY 列 [ASC|DESC]` 追加到当前 SQL 并重新执行。单元格右键菜单同样有这两项，按该单元格所属列排序
- **按值过滤** — 单元格右键「按此值过滤」，弹出面板：上半区列出该单元格的值对应的 `=` / `<>` / `>` / `>=` / `<` / `<=` / `LIKE` / `NOT LIKE` 八种条件（`LIKE` 自动补 `%值%`），点击即生成 `WHERE` 条件重跑 SQL；下半区「自定义」可自选操作符并输入任意值。已有 `ORDER BY` / `LIMIT` 时按新条件替换或重写，保留 `FORMAT` / `SETTINGS` 等尾部子句。多语句或非 `SELECT` / `WITH` 语句时不提供该功能
  - **表头入口（DBeaver 风格）** — 表头右键菜单新增「按此值过滤」，打开后面板顶部是「输入字符过滤列值」搜索框，逐字过滤下方去重后的列值清单（最多 12 项，取当前搜索结果的行）；点任一列值即生成 `列 = 值` 重跑；未选中具体值时下方列出 `=` / `<>` / `>` / `<` / `LIKE` 五种操作符，套用搜索框内容生成条件；搜索框有内容时还可「仅在 xxx 中搜索」，把关键字交给本地搜索框收窄范围
- **多条件筛选（Navicat 风格）** — 结果工具栏「筛选」按钮打开筛选面板，按「列 + 条件组」组织。每个条件组选定一列，组内可加多条规则（组内自动以 `OR` 组合），组之间用组头的 `AND` / `OR` 下拉连接；空值规则自动忽略，面板底部「应用」把结果拼进 `WHERE` 后重新执行。按钮上的数字徽标显示当前生效规则数，「重置」可一键清空
  - 面板顶部实时显示「当前生效条件」的只读 `WHERE` 预览，应用后也能看到拼成了什么
  - 数值列（`Int` / `UInt` / `Float` / `Decimal`，含 `Nullable` 包裹）默认按**数值**比较，生成 `age > 18`；其它列按**文本**比较，生成 `name = 'abc'`。每行规则右侧有「数值 / 文本」切换按钮，可手动改变比较方式；数值模式下若输入不是合法数字，会自动回退为加引号
  - 选 `LIKE` / `NOT LIKE` 时输入框占位符提示「支持通配，留空通配自动补 %」；值里不含 `%` / `_` 时自动补成 `%值%`，已含通配符则原样使用
  - **时间列**（`DateTime64` / `DateTime` / `Date`，含 `Nullable` 包裹）默认按**时间**比较，自动加类型函数包裹：`DateTime64` 列生成 `stat_time >= DateTime64('2026-01-12T18:00:00.123+08:00')`，`DateTime` 列会先剥掉时区再生成 `stat_hour = DateTime('2026-01-12 18:00:00')`，`Date` 列生成 `stat_date <= Date('2026-01-12')`。这样避免了 ClickHouse 报 `Cannot convert string ... to type DateTime (TYPE_MISMATCH)`。每行规则右侧有「时间 / 文本」切换按钮，可改成按字符串比较；输入不是合法时间格式时自动回退为普通字符串字面量
  - 筛选是**服务端**行为：会拼装 `WHERE` 并重新执行查询，与工具栏搜索框（本地过滤）、表头本地排序叠加生效；筛选或排序后分页会自动归位到第 1 页
  - 列名统一用反引号包裹，列名含空格等特殊字符也能生成合法 SQL
- **隐藏列（两种方式）** — 表头右键菜单提供两种隐藏方式：
  - **「隐藏此列」（界面隐藏）** — 仅临时收起不关心的列，表格自动重排不留空位，SQL 不变；导出、复制整行、复制 INSERT 都会**按当前可见列裁剪**，不会带入多余列。同一菜单「恢复全部隐藏列」一键还原（右侧显示当前已隐藏数量），重新查询结果后隐藏状态自动重置。
  - **「隐藏此列（改写 SQL）」** — 真正从 `SELECT` 投影列表里删掉该列并自动重新执行，数据层也不再返回该列，适合想让结果与导出彻底干净的场景。支持单条 `SELECT` / `WITH` 查询；`SELECT *` / `t.*` 会自动按当前结果列展开成显式列名后再删（多表 `a.*, b.*` 各自展开）。当 `*` 与计算列混排（如 `SELECT *, 1 AS k`）时，删除计算列可以，删除 `*` 里的列会提示无法定位；遇到 `UNION`、多语句或 `EXPLAIN` 等非查询语句则提示无法改写。
- **浮层可拖拽** — 「按此值过滤」与「查看 SQL」两个浮层按住标题栏即可拖动，位置被自动约束在窗口内；关闭后再次打开会回到初始位置。
- **复制字段** — 表头右键可复制该字段的全部值，或复制去重后的值（按换行分隔）
- **手动刷新** — 工具栏「刷新」按钮重新执行当前 SQL；刷新时保留已有结果，避免画面闪空
- **定时刷新** — 下拉选择 5 / 10 / 30 / 60 / 300 秒或「不自动刷新」，选中后工具栏显示「N 秒后刷新」倒计时，到点自动重跑；查询进行中不叠加刷新。间隔会记在本地，下次打开沿用
- **自定义定时刷新** — 下拉右侧齿轮按钮打开自定义对话框，可输入 1–86400 秒的任意整数间隔，生效后同样有倒计时与持久化
- **错误展示** — SQL 错误直接在结果面板里显示，不是弹窗；自动提炼 `Code` 与一句话原因（如「表不存在」「语法错误」「内存超限」），点击「展开原文」可查看完整错误文本
- **执行计划** — 结果工具栏「执行计划」按钮，对当前选中（或全文）的单条语句执行 `EXPLAIN`；下拉可选 `EXPLAIN` / `EXPLAIN AST` / `EXPLAIN PLAN` / `EXPLAIN PIPELINE` 四种模式。空内容或多语句（或 DDL/DML 等不可解释语句）时按钮自动禁用
- **单元格编辑（Navicat 风格，直接改库）** — 双击结果表格中的单元格进入编辑态，改完后 `Enter` 或失焦提交、`Esc` 取消
  - 改完的单元格**不会立即写库**，而是先标为待提交：该单元格文字变为琥珀色显示新值，结果表格下方弹出「已修改 N 处，待应用」操作条，包含三个按钮：
    - **应用修改** — 逐条执行 `ALTER TABLE ... UPDATE ... WHERE ...;`，全部成功后自动按当前查询重新拉取结果，单元格恢复为实际库中值；中途失败则停下并提示失败的 SQL 错误（已执行的部分不可回滚，属 ClickHouse mutation 特性）
     - 执行时后端会自动为 mutation 语句追加 `SETTINGS mutations_sync = 2`，**等服务端 mutation 真正完成才返回**，因此紧接着的刷新能看到新值；若语句本身已显式写了 `mutations_sync`，则尊重你的设置不覆盖
    - **撤销修改** — 清空所有待提交项，表格恢复原值
    - **填入编辑器** — 把待提交的 UPDATE 语句批量填入 SQL 编辑器供人工审查，不执行
  - 结果刷新 / 重新查询 / 翻页后待提交项自动清空，避免把旧行的修改应用到新结果上
  - 定位行的条件来自「定位列」（key 列），**默认全自动，无需任何设置**，按 DBeaver 的三级策略选取：
    1. 结果来自按表查询时，优先使用该表的**主键**（`DESCRIBE` 的 `primary_key` 标记，复合主键则多列 `AND` 拼接）
    2. 无主键时，取第一个「全部非空且值全唯一」的列
    3. 两者都没有时，退化为**用全部列**拼 `WHERE`（此时点「查看 SQL」可核对生成的条件）
  - 选中的列在表头以 `KEY` 徽标标出；表头右键菜单顶部会说明当前策略（主键 / 唯一列 / 全部列 / 手动）
  - 需要覆盖时，表头右键「用作编辑定位列」可手动指定单列，选中后该列优先于自动结果；对同一列再次点击可取消并回到自动模式
  - 仅当结果能定位到**单一源表**（无 `JOIN` / `UNION` / 子查询 / `numbers()` 等）时才允许编辑；来自不可定位源表的结果双击无效并给出提示
  - 若所选取的定位列在该行恰好为 `NULL`，会提示无法生成 `WHERE`，可改选其它列
  - 数值类型列自动输出不加引号的字面量，其余按字符串转义；`Decimal` / 浮点等也走数值判定，避免生成非法的带引号值
- **大结果保护** — 单次查询默认最多返回 5 万行，超出自动截断并在结果面板提示，避免界面卡死。上限可在「帮助 → 查询设置」中调整（100 ～ 1,000,000 行，或勾选「不限制」），设置存于 `settings.json`，重启后保持；非法输入会被自动收敛到合法区间。
- **结果分页** — 结果表格下方固定一条分页栏，左侧显示「第 N 页」，右侧是「上一页 / 下一页」按钮，点击即用 `LIMIT/OFFSET` 重跑查询查看后续数据；仅对单条 `SELECT`（含 `WITH`）查询显示，`EXPLAIN` / `SHOW` / DDL / DML 等不显示。翻页期间按钮自动禁用，并沿用既有的取消能力
- **结果导出** — 结果面板「导出」按钮展开下拉菜单，一次列出 8 种格式：CSV / JSON / JSON Lines / TSV / Excel / Markdown / SQL INSERT / SQL DDL + INSERT，选中后走系统「另存为」对话框；Markdown 适合直接贴到文档或工单。菜单支持键盘操作：打开即聚焦第一项，`↑` / `↓` 切换、`Home` / `End` 跳到首尾、`Enter` 选中、`Esc` 关闭
  - **Excel（.xlsx）** — 真正的 Excel 工作簿，不是改后缀的 CSV：表头加粗并冻结首行、自带筛选箭头、列宽按内容自适应（中文按双宽计算）；数值列仍是数字，可在 Excel 里直接求和；含超长文本的单元格会被截断并标 `...`，避免 Excel 提示文件损坏
  - **JSON Lines（.jsonl）** — 每行一个 JSON 对象，缺列补 `null`，可被 `jq`、日志采集、流式管道逐行消费；比整体 JSON 更适合极大的结果集
  - **TSV（.tsv）** — 制表符分隔，ClickHouse 原生格式；单元格里的制表符与换行会被转义，粘贴到 Excel / Google Sheets 不会串列
  - **SQL DDL + INSERT** — 在纯 INSERT 前面自动补 `CREATE TABLE IF NOT EXISTS`，列类型按取值推断（整数 `Int64`、浮点 `Float64`、布尔 `UInt8`、其余 `String`），可在新库一键建表并回灌数据
  - INSERT 与 SQL DDL 导出会先弹出「目标表」对话框：默认带出侧边栏当前选中的表，也可手动输入 `db.table` 之类的完整表名，确认后再选择保存位置，产物可直接回灌 ClickHouse
  - 导出过程中按钮旁会显示「导出中（N 行）...」进度文案；CSV / JSON / JSONL / TSV / Markdown / SQL 均为边生成边写文件，不先把整张表拼成一个大字符串，内存占用显著降低；Excel 因是压缩容器需在内存中组装，超大数据时内存占用高于文本格式
- **结果复制** — 结果表格右键快速取出数据：
  - 单元格右键：复制单元格 / 复制为 SQL 字面量 / 复制整行（TSV）/ 复制为 INSERT / 复制全部为 INSERT
  - 表头右键：**复制列名**（仅复制当前右键那一列）/ **复制列名（逗号分隔）**（复制全部列名）
  - 「复制为 INSERT」的目标表优先取侧边栏当前选中的表；未选中时生成 `your_table` 占位符，需自行替换
  - 复制成功后在结果工具栏短暂提示，1.5 秒自动消失
- **虚拟滚动** — 结果超过 200 行时只渲染可视区域，5 万行结果也能流畅滚动；表头始终固定

## 查询历史

- 每次执行 SQL 自动记录（SQL、连接、耗时、是否成功），最多保留 200 条
- **Gio 原生版当前已接入**：SQL 工具栏「查询历史」按钮展开 / 收起历史面板，按时间倒序展示 SQL、执行时间、连接 ID、耗时和成功状态
- 支持按 SQL 内容或连接 ID 即时搜索；点击记录将 SQL 回填到当前编辑器
- 支持刷新、删除单条和清空全部；列表读取、删除和清空均在后台执行，结果回到 Gio 主事件循环更新界面，并通过请求序号忽略过期列表响应

## 已收藏 SQL

- 收藏**无条数上限**，也不会被「清空历史」删除 —— 属于你的长期资产
- 收藏服务支持新增、列表、按名称或 SQL 搜索、重命名和删除；同一段 SQL 重复收藏会被拒绝
- **Gio 原生版当前已接入**：SQL 编辑器工具栏「收藏 SQL」将当前 SQL 与连接 ID 一起保存；「收藏 SQL / 收起收藏」按钮展开或收起列表
- 原生列表支持按名称或 SQL 内容即时搜索、刷新、重命名、删除；点击收藏条目可将 SQL 回填到当前编辑器
- 收藏标题为空时由服务自动取 SQL 首个非空行；原生界面当前使用自动标题，尚未提供收藏时自定义标题输入框
- 收藏列表读取、保存、重命名和删除均在后台执行，结果回到 Gio 主事件循环更新界面；列表刷新采用请求序号隔离过期响应

## 标签页恢复

- 关闭程序时自动保存标签标题与 SQL，下次启动恢复（结果不恢复，需要重新执行）

## 数据库 / 表 / 视图浏览

- **侧边栏树** — 点击数据库名展开，默认显示该库所有**表**；如果库里有视图，会在表下方单独展示「**视图**」分区（眼睛图标，悬停显示引擎）。普通 `View`、`MaterializedView`、`LiveView` 都会被归入视图区。
- **单击表名 / 视图名** — 直接在结果面板**预览数据**（自动 `SELECT * FROM db.name LIMIT 10` 并执行），选中项高亮标识。空表（0 行）会显示明确的空态提示而不是一直转圈：图标 +「查询完成，0 行」+「该表暂无数据」+ 列数与耗时；若空结果来自服务端筛选，提示改为「当前筛选条件下无匹配，可尝试放宽条件」并提供「清除筛选」按钮一键重跑原 SQL
- **执行中的状态区分** — 首次执行且无旧结果时显示居中转圈 +「正在查询…」；已有结果时刷新/翻页则保留旧表格并在工具栏显示「刷新中…」小标识，不再整块空白
- **右键表名 / 视图名** — 菜单支持：
  - `SELECT * LIMIT 10` — 快速预览前 10 行
  - 查看 DDL — `SHOW CREATE TABLE` 结果写入编辑器
  - 编辑表结构 — 打开编辑 Modal
  - 删除表 — 带红色确认弹窗

## 可视化建表

**入口**：鼠标悬停数据库名 → 右边小 `+` 按钮，或右键数据库 → "在此数据库创建表"

支持配置：

| 字段 | 说明 |
|---|---|
| 表名 | 必填 |
| 注释 | 可选 |
| 引擎 | 下拉选择（26 种常用），默认 MergeTree |
| ORDER BY | MergeTree 系列必填，自动提示 |
| PARTITION BY | 可选 |
| PRIMARY KEY | 可选，不填则用 ORDER BY |
| SETTINGS | 可选，如 `index_granularity = 8192` |
| 列定义 | 名称 / 类型（下拉 42 种） / 默认值 / 注释，支持上下移动、删除 |

底部实时 **SQL Preview** 面板，提交前可直接确认。

## 可视化编辑表

**入口**：右键表名 → "编辑表结构"

打开后自动从后端加载当前表结构，三类变更操作：

| 操作 | 标记 | 生成 SQL |
|---|---|---|
| 修改列类型 / 默认值 / 注释 | 蓝色 **MOD** | `ALTER TABLE ... MODIFY COLUMN ...` |
| 重命名列 | 黄色 **REN** | `ALTER TABLE ... RENAME COLUMN ... TO ...` |
| 新增列（支持 FIRST / AFTER） | — | `ALTER TABLE ... ADD COLUMN ...` |
| 删除列 | 红色 **DROP** | `ALTER TABLE ... DROP COLUMN ...` |

底部实时预览所有变更对应的 ALTER 语句，按顺序逐条执行，中途失败会报出具体哪条 SQL 出错。

> **边界处理**：编辑表时，如果某列当前类型不在 42 种预设里（如 `Decimal(15, 4)`），它会自动加入下拉选项，不会丢失原值。

## 配置导入导出

在菜单中打开「导入 / 导出配置」：

**导出**，支持 5 种格式：

| 格式 | 用途 |
|---|---|
| JSON | 本工具原生存档，可完整回导 |
| YAML | 便于人工编辑与阅读 |
| CSV | 可用 Excel 等表格工具打开 |
| DSN (URI) | 一行一个 `clickhouse://user:pass@host:port/db`，便于脚本 / 其他客户端使用 |
| DBeaver | 生成 DBeaver `data-sources.json` 结构，可直接导入 DBeaver |

- 默认**脱敏**（不导出密码），勾选后才会带上明文密码
- 支持复制到剪贴板，或「另存为」指定路径

**导入**，支持格式：JSON（含 DBeaver 结构）/ YAML / CSV / DSN

- 可自动识别格式，也可手动指定
- 两种模式：
  - **覆盖** — 用导入内容替换当前全部连接与分组
  - **合并** — 同名分组复用，ID 冲突自动重分配，或与现有配置共存
- 导入报告提示本次导入了多少分组和连接

> **安全提示**：导出的文件如果包含密码，就是明文存储。请勿随手分享到聊天工具或提交到代码仓库。不勾选「包含密码」时导出的是脱敏版本，可安全分享。

## 配置文件

配置存放在用户目录下：

| 文件 | 内容 |
|---|---|
| `connections.json` | 连接与分组（**含明文密码**） |
| `history.json` | 查询历史（最多 200 条） |
| `saved_sql.json` | 已收藏 SQL（无上限，不受清空历史影响） |
| `tabs.json` | 标签页快照（标题 + SQL） |

可通过菜单「打开配置文件夹」快速定位。

> **当前限制**：密码以明文形式保存在 `connections.json` 中，未做加密。单人本机使用场景下这是有意的取舍——若需加密，需权衡密钥管理（密钥存哪里、换机器如何迁移）的复杂度。请确保该目录不被他人访问，也不要把它同步到公开的云盘或代码仓库。
