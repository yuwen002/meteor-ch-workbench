# 功能说明

> 本文档描述当前 Fyne v2 GUI 版本的实际功能。项目已从 Wails + Vue 迁移至纯 Go + Fyne。

---

## 连接管理

- **新建连接** — 侧边栏底部「+ 连接」按钮，表单填写 Name / Host / Port / Database / Username / Password / 所属文件夹
- **编辑连接** — 右键连接 → 编辑连接，或侧边栏历史面板 → 连接管理
- **删除连接** — 右键连接 → 删除连接，弹窗确认
- **测试连接** — 保存前可先测试连通性，失败信息直接显示
- **文件夹分组** — 右键文件夹可编辑名称或删除；删除文件夹时连接自动回归根级
- **连接测试（全局）** — 右键任意连接节点 → 测试连接

## SQL 编辑器

- **快捷键执行** — `Ctrl/Cmd + Enter` 执行 SQL
- **取消查询** — 查询运行中按 `Esc`，或点击工具栏「取消」按钮（按钮由 Run 变为 Cancel）
- **多标签页** — 同时开多个查询标签，各自独立的结果 / 错误 / 加载状态；关闭程序时自动保存，下次启动恢复

## 结果表格

- **列宽自适应** — 采样前 200 行自动计算列宽（80~420 范围），首列显示原始行号
- **行数统计** — 状态栏实时显示总行数；搜索时变为「共 N 行（搜索匹配 M 行）」
- **结果集搜索** — 结果工具栏内嵌搜索 Entry，输入即过滤；大小写不敏感、任意列子串匹配；右侧 × 按钮一键清空。**本地行为**，只过滤已加载的结果，不发新查询
- **结果分页** — 结果工具栏右侧 pageSize 下拉（50 / 100 / 200 / 500）+ 上一页 / 下一页按钮，自动拼接 `LIMIT/OFFSET` 重跑查询。**已有 LIMIT 的 SQL 跳过拼接**
- **定时刷新** — PopUpMenu 选择 5s / 10s / 30s / 停止，到点自动重跑；查询进行中不叠加刷新
- **EXPLAIN 执行计划** — 工具栏「执行计划」按钮，自动去重 SQL 中已有的 EXPLAIN 前缀后执行
- **单元格编辑** — 点击单元格 → Dialog 生成 `ALTER TABLE ... UPDATE ... WHERE ...`，自动从 SQL 的 `FROM` 猜目标表名；三种值类型（整数 / 浮点 / 字符串）正确处理引号
- **结果表格右键菜单** — 先单击选中单元格 → 右键弹出菜单：复制单元格 / 复制为 SQL 字面量（正确加引号转义）/ 复制整行（TSV 制表符分隔）/ 复制整行（INSERT 语句，自动带列名和表名）/ 在编辑器生成 UPDATE（全字段 WHERE 子句）
- **结果导出** — 导出按钮展开下拉，注册表自动感知可用格式；走系统「另存为」对话框，`ExportResultTo` 直写 io.Writer。支持格式：CSV / JSON / JSON Lines / TSV / Markdown / SQL INSERT / SQL DDL + INSERT / YAML / XML / XLSX

## 数据库 / 表 / 视图浏览（侧边栏树）

- **懒加载** — 点击连接自动展开数据库列表；点击数据库展开表和视图；本地 `dbCache` 缓存避免重复请求
- **单击节点** — 点击表 / 视图 → ConfirmDialog 选择 `SELECT * LIMIT 100` 或 `DESCRIBE TABLE`；点击数据库 → 自动填入 `USE db; SHOW TABLES FROM db`
- **右键菜单（按节点类型分发）**：
  - **连接** → 测试连接 / 编辑连接 / 删除连接
  - **文件夹** → 编辑文件夹 / 删除文件夹
  - **数据库** → USE 数据库 / 查看所有表
  - **表** → SELECT * LIMIT 100 / DESCRIBE TABLE / SHOW CREATE TABLE / **TRUNCATE TABLE**（⚠️ 二次确认）/ **DROP TABLE**（⚠️ 二次确认）
  - **视图** → SELECT * LIMIT 100 / DESCRIBE VIEW / SHOW CREATE VIEW

## 侧边栏四 Tab

| Tab | 内容 |
|---|---|
| **连接** | 数据库树 + 「+ 连接」「+ 文件夹」按钮 |
| **历史** | 查询历史列表（SQL / 连接 / 耗时 / 成功状态），点击回填编辑器，支持清空 |
| **收藏** | 收藏的 SQL 列表，点击回填；工具栏「+」收藏当前编辑器 SQL |
| **配置** | 配置导入导出对话框（注册表自动感知格式） |

## 查询历史

- 每次执行 SQL 自动记录（SQL、连接、耗时、是否成功），最多保留 200 条
- 支持删除单条、清空全部

## 收藏 SQL

- 收藏 **无条数上限**，不受「清空历史」影响
- 同一段 SQL 重复收藏会被拒绝

## 标签页恢复

- 关闭程序时自动保存标签标题与 SQL（`tabs.json`），下次启动恢复

## 配置导入导出

导出支持 5 种格式，默认脱敏（不导出密码）：

| 格式 | 用途 |
|---|---|
| JSON | 本工具原生存档，可完整回导 |
| YAML | 便于人工编辑与阅读 |
| CSV | 可用 Excel 等表格工具打开 |
| DSN (URI) | 一行一个 `clickhouse://...`，便于脚本使用 |
| DBeaver | 生成 DBeaver `data-sources.json` 结构 |

导入支持自动识别格式（JSON / YAML / CSV / DSN），支持覆盖或合并模式。

## 配置文件

存放在用户目录下：

| 文件 | 内容 |
|---|---|
| `connections.json` | 连接与文件夹（**含明文密码**） |
| `history.json` | 查询历史（最多 200 条） |
| `saved_sqls.json` | 收藏 SQL（无上限） |
| `tabs.json` | 标签页快照（标题 + SQL） |

可通过菜单「打开配置文件夹」快速定位。

> **当前限制**：密码以明文形式保存在 `connections.json` 中，未做加密。单人本机使用场景下这是有意的取舍。

## 已知技术债

- **Fyne `widget.Table` 无内建搜索 / 排序**：搜索功能已自研（`filteredRows` 映射），排序暂未实现
- **Fyne Tree 无公开选中 API**：右键菜单通过缓存 `lastSelectedNode` + `treeWrapper` 包装器绕过
- **分页不支持服务端筛选**：是前端拼接 LIMIT/OFFSET，不支持 ClickHouse 的 `IN` 过滤式分页
- **SQL 编辑器无语法高亮 / 自动补全**：Fyne Entry 是纯文本控件
- **无连接拖拽分组**：需要手动编辑连接归属的 FolderID
